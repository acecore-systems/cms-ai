# Haikuへの移行案（未配備）

通常CMSと新規SEO文章処理をAnthropic Messages API `claude-haiku-5-5`へ変更する。画像入力、既存の認可・編集制限、JSONのローカル検証を維持する。調査・検索は既存Lunaを使う。実API、実画面、課金と本番反映は未確認。

新規SEO jobは追記専用のv3モデル行と監査行を保存する。v2の行、予約、応答・復旧証跡は書き換えず、v2でDeepSeekが必要になった段階は予約・送信前に停止する。従来のv2証跡を読む機能は維持する。v2 jobをv3へ付け替えない。失敗・応答不明時は予約を保持する。

旧v2のhigh失敗からlowへ変更する専用救済も、DeepSeekが必要な段階で停止する。v3の新規校閲は最初からlow契約であり、失敗時の自動再送や新たな救済経路は追加しない。

SEOの1 run 1.25 USD・通常月7 USD上限は増やさない。Haikuは長文側の入力0.50 / 出力2.50 USD/Mを全リクエストに適用し、cache割引を使わない。`UTF-8 bytes + 8192`を入力token上限とする既存方式を用いるが、Anthropicによる厳密な保証は未確認。利用量超過は応答を拒否し、予約は保持する。2026-11-04の利用者承認により料金設定は無期限とし、日付による自動停止を撤廃した。単価は見積値として版管理し、価格変更時に更新する。プロバイダーの将来の価格を保証するものではない。最大48,000出力tokenは変更しない。

標準配分の合成fixture（各ファイル1,000 bytes）では、1〜4言語の最大予約はそれぞれ775,744 / 929,007 / 1,082,270 / 1,235,533 microUSD、5〜9言語は上限超過でAI呼出し前に停止する。実記事への適合や品質を保証しない。

## 配備と復旧

1. 統合・配備の承認後、Anthropic Consoleで適切なworkspaceのAPI keyを用意し、値をチャット、履歴、ログへ転記しない。Cloudflareの`cms-ai` Worker secretとして名前 `ANTHROPIC_API_KEY` を安全な対話入力または管理画面で登録する。登録時点でWorker設定へ反映されるため、本番操作として扱う。
2. 新規受付を停止し、進行中jobと予約を確認する。D1と非公開R2の証跡を保持して `0046_seo_haiku_models.sql` を適用し、旧行と新triggerを確認する。CMS Workerを配備してから受付を戻す。SEO schedulerや通知の設定は変更しない。
3. 最小限の実API試験で画像、schema、拒否・上限、料金、結果保存を確認する。Secretsの存在だけで動作確認としない。期限前に料金と使用量の再確認を行う。
4. 差戻し時はまずSEO受付・生成を停止し、進行中jobの状態と未確定予約を保全する。旧Workerはv3を認識できず、v3 jobを旧契約として解釈し得るため、v3 jobが残る状態で旧Workerへ戻して受付を再開しない。旧証跡は削除・更新せず、CMSの通常会話だけを復旧する場合も別途影響を確認する。新規v3を安全に扱える修正版での復旧を優先する。
