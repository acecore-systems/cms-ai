# 2026年10月だけの月予算例外

利用者の2026-10-23明示承認により、JSTの2026年10月のみ月上限を10 USDとする。11月以降を含む他の月は7 USD、1回1.25 USD、全工程最大1205876 microUSD、30分・3候補/1記事・9言語・Draft終了は維持する。

新規0015は予算INSERT triggerの月比較のみを変更する。旧0011/0012、全予約・未確定予約・期限・runの保存済み上限・旧監査は変更しない。claim前の無課金preflightとSQLはいずれも`month_jst === 2026-10`だけ10Mとし、JST境界で11月の7Mへ戻る。2027年10月へ自動延長しない。

管理者は適用前後の全行一致を確認し、0015適用後にコードを配備する。現在予約4627313に追加実確認最大3回と10/26用1250000を足した上限は9494941 microUSD。最大3回・成功時終了・10/26枠保持は今回の管理実行条件であり、このmigrationが試行を起動したり自動リトライを追加したりすることはない。本番適用・有料実行は運用担当者が行う。

資料選定・品質判定・URL証跡条件・原文量・入力/出力capをこの変更で緩和しない。予算枠の増加は生成・AI校閲・Draftの成功を保証しない。
