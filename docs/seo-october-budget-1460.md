# 2026年10月の承認済み月額上限14.60 USD

2026-10-25の利用者指示「必要なら予算追加して実確認して」に基づき、JSTの2026年10月だけ13.60から14.60 USDへ変更する（+1.00 USD）。通常月7 USD、1論理run上限1.25 USD、10月26日用1.25 USD留保と、その解除時刻1792972800000（2026-10-26 00:00:00 UTC）を維持する。各runの元deadlineや品質検査も変更しない。

既存予約12,099,660 + 追加1run上限1,250,000 + 週次留保1,250,000 = 14,599,660 microUSD。14.59 USDでは不足し、セント単位の最小上限は14.60 USDとなる。留保前の利用枠は13,350,000 microUSD、追加runの最大予約後も340 microUSDと週次留保1,250,000 microUSDが残る。予約額は実請求額とは区別し、未確定callや失敗callの予約を返金しない。

0040は0039に続き、seo_budget_cap・seo_fallback_first_call_fit・seo_model_reservationの3triggerの月上限と留保後上限だけを変更する。通常月・run上限・留保解除時刻・監査条件はそのまま。旧migrationや全履歴行、記事lock、根拠、期限、既存予約は変更しない。

検証対象はJST月境界、11月・翌年の通常上限復帰、月上限の1 microUSD超過、1回上限、全工程のfallback事前判定、D1の監査付き競合予約、全旧行・他schema保持、週次留保と解除時刻。実台帳の取得・ローカル再現・本番適用後比較は親担当が行う。

Git pushにより本番buildが起動するため、親担当はレビュー後にmigrationをコード統合前に適用し、旧行保持を照合する。続いて統合・配備・最新台帳確認を行い、承認範囲の追加1論理runを実行する。本変更のCI成功だけでは生成・AI校閲・Draft PRの初成功を確認したことにならない。本実装担当はD1適用・merge・deploy・AI開始を行わない。
