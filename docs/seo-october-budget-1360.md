# 2026年10月の承認済み月額上限13.60 USD

2026-10-24の利用者承認により、JSTの2026年10月だけ12.48から13.60 USDへ変更する（+1.12 USD）。修正後の実AI確認を追加1回実施する。通常月7 USD、1回1.25 USD、10月26日用1.25 USD留保、元の期限、品質検査、既存予約は維持する。

本番台帳の予約11,091,530 microUSDに対し、留保前の利用枠は12,350,000 microUSD、留保後余力は1,258,470 microUSDとなる。追加1回で上限1,250,000 microUSDを予約しても8,470 microUSDと10月26日用1,250,000 microUSDが残る。これは実請求額ではなく保守的な予約額であり、未確定callを返金しない。

0039は3つの予算triggerの上限値だけを変更する。旧migrationを改変せず、新しいmigrationをコードの統合前に適用する。全旧行、記事lock、期限、その他schemaが変わらないことを実台帳のローカル再現と適用後の再読で照合する。

10月境界、11月以降の復帰、1回上限、週次留保、競合予約、全工程の事前判定を検証する。成功確認は本番の日本語生成・AI校閲・Draft PR作成の実結果をもって判断し、CI成功とは区別する。
